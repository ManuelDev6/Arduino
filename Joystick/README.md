# Arduino-Joystick
Uno Sketch Arduino che tramite un modulo joystick fa accendere o spegnere 2 led in base al movimento eseguito.

## Funzionamento del circuito
* Joystick direzionato a sinistra: Led 1 acceso
* Tasto Joystick premuto: Led 2 spento

## Materiale utilizzato
* Scheda Arduino
* Modulo Joystick
* Breadboard
* Cavi Jumper
* Cavi femmina/maschio
* Led
* Resistenze 220 ohm
