# Arduino-ShiftRegisterButton

Uno sketch Arduino che tramite un registro a scorrimento 74HC595 fa accendere 1 led alla volta per 1 secondo.

## Funzionamento del circuito
Il circuito presenta 2 tasti che decidono la sequenza di scorrimento dello shift register:
<br><br>
Tasto 1 ---> Sequenza MSB-First
<br>
Tasto 2 ---> Sequenza LSB-First

## Materiale utilizzato
* Scheda Arduino
* Shift Register 74HC595
* Breadboard
* Cavi jumper
* Tasti
* Led
* Resistenze 220 ohm
