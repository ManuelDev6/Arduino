# Arduino-ServoMotore 2Button
Uno sketch Arduino che fa muovere un servomotore in una determinata posizione in base al tasto premuto.

## Funzionamento circuito
* Tasto 1: direzione -180 gradi
* Tasto 2: direzione 180 gradi

## Materiale utilizzato
* Scheda Arduino
* Servo motore
* Breadboard
* Cavi jumper
* Tasti
* Resistenze 220 ohm
