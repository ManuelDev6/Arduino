# Arduino-Joystick Led
Uno sketch Arduino che tramite un joystick fa accendere il corrispettivo led in base al movimento eseguito.

## Funzionamento del programma
* Joystick direzionato a sinistra: Led X1 acceso
* Joystick direzionato a destra: Led X2 acceso
* Joystick direzionato sù: Led Y1 acceso
* Joystick direzionato giù: Led Y2 acceso
* Tasto Joystick premuto: Led SW premuto

## Materiale utilizzato
* Scheda Arduino
* Modulo joystick
* Breadboard
* Cavi jumper
* Cavi femmina/maschio
* Led
* Resistenze 220 ohm.
